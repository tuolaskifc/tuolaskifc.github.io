> 2026 年夏天的两个小项目，都是"不想被剧透"驱动的。

---

## 起因

我是个切尔西球迷，第二天想好好看一场比赛录播，结果页面上的比分、推荐位标题、栏目封面早就把结果摆在那儿了。我又不想熬夜赶直播——于是干脆自己动手把剧透源头堵上。

两个浏览器插件就这么搓出来了，**都上架了 Edge 插件商店**，代码也开源在 GitHub。

## 🔴 咪咕防剧透

在 **咪咕体育（miguvideo.com）** 找比赛录播时不看到结果。

- **自动遮罩比分**：`3-2`、`3比2`、`3:2`、以及 536 个结果暗示词（按 10 类管理）→ 替换成遮罩符号（CSS 瞬时隐藏，看不到中间态）
- **标题替换**：所有视频/资讯标题整体替换成"xxx是冠军"（文案可自定义），从源头杜绝剧透
- **整块隐藏泄露栏目**："最新资讯 / 赛场速递"这类标题和封面都泄露结果的栏目，整个区块隐藏
- **拦截自动播放预览**：频道页顶部的自动播放视频直接拦停（在播放器加载前就替换 `play()`），需要看视频的观赛页不受影响
- **老球迷模式**：所有内容文字变透明，只留队徽/图片认队；可点击的按钮（如"集锦/回放"、跳过广告）保留可见
- **广告倒计时**：观赛页广告播放时显示"广告还剩 Xs"

- 商店：Microsoft Edge 插件商店搜索「咪咕防剧透」/ "Migu Spoiler Blocker"
- 仓库：https://github.com/tuolaskifc/migu-spoiler-blocker

## 🟢 爱奇艺防剧透

在 **爱奇艺体育（sports.iqiyi.com）** 找比赛录播时不看到结果。

咪咕那个的核心机制同样搬过来（534 → 536 词，遮罩策略一致），针对爱奇艺多做一些适配：

- **整块隐藏资讯栏目更激进**：爱奇艺的栏目分类比咪咕细（欧冠资讯 / 西甲资讯 / 欧联资讯 / 亚冠资讯 / 英超资讯…）全部隐藏
- **屏蔽词库分 10 类可单独开关**：比分、球队状态、积分、射手、伤停等可独立勾选
- **可自定义遮罩样式 + 标题替换文案**

- 商店：Microsoft Edge 插件商店搜索「爱奇艺防剧透」
- 仓库：https://github.com/tuolaskifc/iqiyi-spoiler-blocker

## 用法（都是）

1. 打开 `chrome://extensions/` 或 `edge://extensions/`
2. 右上角开"开发者模式"
3. 点"加载已解压的扩展程序"，选对应文件夹
4. 打开对应网站，工具栏图标点开 → 勾选/取消各项开关

点"设置遮罩 / 屏蔽词…"可以管理分类词库（10 类可折叠）、遮罩样式、标题替换文案。

## 已知边界

- 两个平台都是动态渲染的 SPA，改版频繁。本插件尽量用通用文本规则 + 弱选择器，改版后可能漏网或误伤，欢迎把"哪里还泄露了比分"的具体页面发回来修。
- 视频**画面内部**的比分条属于图像，本插件不遮挡（录播从头看时通常不涉及）。
- 只对各自域名生效（咪咕 miguvideo.com / 爱奇艺 sports.iqiyi.com），其它网站不处理。

## 一些体会

1. **浏览器插件没有想象中难**：MV3 manifest + 注入脚本 + 词库匹配，核心逻辑其实很简单。
2. **难的是"该遮什么"**：比分在页面哪里、剧透藏在哪些文案里，需要一个个页面去观察和调试——这部分是最花时间的。
3. **vibe coding 很顶**：大部分代码是和 AI 结对写出来的，比自己从头写快得多。
4. **看球的副产品**：起因是不想熬夜，但搓出来之后发现对追剧/综艺也一样有用——本质都是"别剧透我"。

如果看球/追剧时也被剧透困扰，欢迎去 Edge 商店装一个，或者去 GitHub 提 issue / star ⭐
