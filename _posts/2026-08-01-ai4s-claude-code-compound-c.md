> 这篇文章梳理我在张韶光老师「AI4S 交叉实践课程」中的一次实践——用 Claude Code 配合多种 AI 工具，对未知化合物 C 进行 NMR + ESI-MS 综合结构确证。**本文严格区分三类表述：直接实验数据 / AI 或模型输出 / 化学解释**，并标注尚未证实的假设。

## 一、课程的核心命题

张老师在第一节课就划了一条线：

> **AI 不是答案机器，而是证据链构建工具。**

这门课不是"上传谱图 → 复制答案"的培训，而是一次科研判断训练。最低目标是让学生意识到——"模型答案"与"化学结论"之间，隔着一整套证据审核流程：

```
问题定义 → 数据质量 → 模型输出 → 化学核查 → 正交验证
```

一个可信的结构结论需要四要素：不同证据相互支持、没有明显内部矛盾、关键假设经过核查、知道还有什么未被证明。

## 二、任务与数据

**任务**：给定化合物 C 的 ¹H NMR、¹³C NMR、³¹P NMR 原始谱图 + ESI-MS，提出 C 最合理的结构假设，建立完整证据链。

**可能的杂质与溶剂背景**（来自反应分析）：C₆D₆、二乙胺、二乙胺合硼烷、二碘丙烷、硼烷、THF。

这是关键一步——**先验信息决定候选空间的上限**。如果连反应里有什么杂质都没理清，后面 AI 给出的任何"排名第一"都可能是错的。

## 三、Claude Code 在这次实践中的角色

课程强调：不要把"LLM"和"专用谱学模型"混为一谈。真正的 AI4S 工作里，更重要的是 NMRium、SpecXMaster、SIRIUS 这类专用小模型和数据库工具。但通用大模型 + 代码执行能力（也就是 Claude Code 这种）能做一件很关键的事——**把离线、可审计的小工具链搭起来**。

实践期间，nmrdb.org、NMRShiftDB2、NIST Webbook 等在线数据库均因网络问题无法访问。于是我用 Claude Code + RDKit 在本机搭了一个基于**基团贡献法**的 ¹H NMR 经验预测器，核心思路是：

$$\delta = \delta_0 + \sum_i \text{取代基效应}_i$$

其中 $\delta_0$ 是基准值（如 $-\text{CH}_3$ 基准 $\approx 0.9\ \text{ppm}$），求和项是所有邻位、间位取代基对电子密度的扰动。

推理链每一步都可审计：

```
SMILES 输入
  → RDKit 解析分子图
  → 遍历每个 H 原子，检查 6 层信息：
      ① 连在什么原子上 (C/O/N)
      ② 该 C 的 H 数量 (CH₃ / CH₂ / CH)
      ③ 邻近官能团类型 (芳环/炔键/P/杂原子)
      ④ 所在环是否芳香 (sp² 键级 1.5)
      ⑤ 环大小 (5/6 元环)
      ⑥ 是否共轭体系
  → 匹配化学位移经验表 → 赋值 δ ± 0.3 ppm
  → 输出预测报告
```

这个工具的定位很清楚：**基团贡献法经验估算，等同于 ChemDraw 基础预测级别，精度 ±0.3 ppm**。定性归属可用，精确引用不够。它的价值不在于"替代在线数据库"，而在于——**当外部资源不可用时，仍能给出一个可复现、可审计的基线预测**，让证据链不至于断在"没有预测"这一步。

## 四、关键 NMR 证据：P 连接的碳

化合物 C 含磷（³¹P NMR 有信号），这是结构判断的核心难点。不同工具对 P−CH 的预测分歧很大：

| 工具 | P−CH 预测 (ppm) |
|------|----------------|
| ChemDraw | 1.3 / 1.4 |
| NMRium | 3.99 / 1.91 |
| DeepSeek 推断 | 1.8–2.2 / 1.0–1.6 |
| **实际谱图归属** | **2.13 / 2.32** |

这里有一个重要的方法论点：**不能因为某个工具的数字接近实际就认为它"对"**。DeepSeek 的区间恰好覆盖了实测值，但区间宽到 ±0.6 ppm，这更像是"运气"而非"精度"。真正支持结构假设的，是耦合裂分模式的一致性——

- ChemDraw 预测的裂分比例 $1:6:15:20:15:6:1$ 与原始谱图吻合
- 耦合常数 $J \approx 6.9\ \text{Hz}$（ChemDraw 6.92、NMRium 6.8、实测 7 Hz，换算 $0.014\ \text{ppm} \times 500\ \text{MHz}$）

**多重性与耦合常数的同时符合，比单一化学位移的接近更有说服力。** 这是课程反复强调的：回看第 1-3 步的输入和第 5 步的核查，不要只盯第 4 步的排名。

## 五、AI 工具的能力分层

这次实践用了四类工具，能力差异非常明显：

**通用大模型（DeepSeek、Gemini、ChatGPT pro）**

- DeepSeek / Gemini：能力一般的大模型难以独立完成整个任务，提供的信息多而杂，需要使用者有判别能力提取正确信息。Gemini 在底物识别上有问题，遇到难以解释的问题时倾向于强行解释而非反思结构。
- ChatGPT pro：可以独立完成复杂任务——对图像多次裁剪识别提高准确度，搜索类似结构的 NMR 自行验证。但这里有一个**尚未回答的问题**：GPT pro 的工作具有普遍性吗？单次成功不能推出方法可靠。

**专用小模型（SpecXMaster）**

SpecXMaster 需要精确的输入数据，更多起交叉验证作用。给它不同粒度的输入（只给元素组成 / 加上 Dipp 基团 / 给完整分子式），输出会变化——这正好说明了**先验层对候选生成的决定性影响**。

> ⚠️ 按课程红线：以上均为"模型给出/识别为……"，**不是**"AI 证明了……"。

## 六、ESI-MS 的正交验证

ESI-MS 提供了与 NMR 正交的证据。DeepSeek 在只给谱图和预测结构的情况下，指出了可能的氧化情况：

$$234 + 16 + 23 = 273$$

这个加和（+16 氧化、+23 钠加合）与实测 $m/z\ 273$ 符合得很好。精确质量计算也佐证了结构假设：

| 离子 | DeepSeek 计算 | 实测 |
|------|--------------|------|
| $m/z\ 273$ | 273.1379 | 273.1926 |
| $m/z\ 280$ | 280.1463 | 280.2651 |
| $m/z\ 263$ | 263.1564 | 263.1912 |

其中 $m/z\ 263 = 234 + 29$，符合 +29 加合峰（乙基加合或乙醛加合）的特征。

> 这部分是"AI 输出与实验数据共同支持……，但仍需……"——不是"AI 证明了"。

## 七、六层失败模式与本次实践的对照

课程给了六层失败模式，这次实践几乎每一层都踩到了：

| 层 | 问题 | 本次表现 |
|----|------|---------|
| **输入层** | 截图/OCR、基线、相位 | MestReNova 处理原始 FID，去杂质溶剂 |
| **特征层** | 峰拾取、溶剂峰、杂质峰 | 1.3 ppm 幽灵峰（极易从硅胶、器材引入）需识别 |
| **先验层** | 错误分子式、候选库太窄 | 反应杂质分析决定候选空间 |
| **排序层** | Top-1 ≠ 真结构 | SpecXMaster 不同输入给不同排名 |
| **化学层** | 异构体、立体化学 | P 连接的 C 仍不明确 |
| **报告层** | 把模型输出写成实验事实 | 全文严格区分三类表述 |

## 八、局限性与后续实验

诚实地写下还没解决的问题：

1. **P 连接的 C 仍然不明确**——化学位移预测分歧大，需要 2D NMR（HSQC/HMBC）确认
2. **质谱峰只分析了少量**——还有多个峰未归类
3. **GPT pro 的工作是否可重复**——单次成功不能推出普遍性，需要更多样本测试

后续最有信息量的实验是 2D NMR（HMBC 看 P−C−H 的远程耦合）和标准品对照。

## 九、个人反思

这次实践最大的收获不是"确定了化合物 C 的结构"，而是理解了 AI4S 的方法论：

- **AI 提高效率的地方**：数据处理、候选生成、文献检索、交叉验证。Claude Code 搭的离线预测器让我在外部数据库不可用时仍能保持证据链完整。
- **AI 误导风险的地方**：语言流畅 ≠ 科学正确。DeepSeek 给的宽区间"恰好"覆盖实测值，如果只看数字接近就会误判精度。
- **以后如何核查**：每次接受 AI 输出前，过一遍老师给的 10 问清单——输入是原始数据还是截图？相位基线检查了吗？分子式/加合物可靠吗？候选空间包含正确答案吗？Top-5 候选逐一比较了吗？……

> 高质量项目的标志：不只展示"成功案例"，还展示"模型何时不应被信任"。

这门课让我意识到，**化学人的核心价值不在"会用 AI"，而在"能判断 AI 输出在化学上成不成立"**。AI 越强，这个判断能力越值钱。
